# 株式会社Gizumo

**人の未来を創る**

ビジネスのクリエイティブな領域は人によって創られるという前提のもと、ITという得意分野を中心にクリエイティブ集団を創り出し続ける事を約束とします。

## 私たちについて

株式会社Gizumoは、システム開発とWebサイト制作を中心に、ヘルプデスクや社内SE代行といったIT業務代行、エンジニア派遣まで幅広く手がけています。

このページでは、私たちがどのような技術を使い、どのように開発を進めているかを紹介します。

## 開発体制

### レビューは必ず行います

案件の規模や性質を問わず、コードレビューを実施する方針を全社で統一しています。属人化を防ぎ、品質を一定に保つための土台と位置づけています。

### ブランチ運用はプロジェクトに合わせます

リリースフローの性質はプロジェクトによって異なるため、Git Flow と GitHub Flow を使い分けています。ひとつの運用をすべての案件に当てはめることはしていません。

### CI/CD は適用範囲を広げています

現在は一部のプロジェクトで導入している段階です。属人化の排除を目的に、適用範囲を積極的に広げていく方針です。

### チームは案件単位で編成します

案件の規模にもよりますが、最小構成でもPMと実装者の2名以上で進めます。

### 技術選定の裁量は案件によって異なります

| 案件の種類                       | 技術選定                                   |
| -------------------------------- | ------------------------------------------ |
| 自社サービス                     | 提案が通りやすい環境です                   |
| 受託（0→1開発・リプレイス）      | 提案が採用されるケースも多くあります       |
| 受託（既存サービスの保守・運用） | クライアントの指定に沿うことが多くなります |

社内向けのサービスを新規開発する際に、新しい技術を採用した実績もあります。

### 学習を支援する制度があります

- 書籍購入補助
- 資格支援制度
- 外部講師を招いたPMセミナーの定期開催
